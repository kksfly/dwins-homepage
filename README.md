# 주식회사 인스보험중개 (INS Corp.) 공식 웹사이트

대한민국 기업 고객과 다국적 기업을 위한 프리미엄 독립 보험 및 재보험 브로커리지 기업, **주식회사 인스보험중개(INS Corp.)**의 공식 반응형 웹사이트입니다.

## 📌 주요 특징
- **반응형 웹 디자인 (Responsive Web)**: 데스크톱, 태블릿, 모바일 기기 완벽 지원 (1200px 기준 사이드 드로어 메뉴)
- **최신 웹 표준 기술**: 순수 HTML5, CSS3, 바닐라 JavaScript 기반의 가볍고 빠른 성능
- **프리미엄 라이트 테마**: 화이트 & 코퍼레이트 블루 기반의 신뢰감 있는 비즈니스 디자인
- **글로벌 네트워크 연계**: Assurex Global, Verspieren, Brokerslink 파트너십 소개 및 주요 사업 영역(Property, Casualty, Marine, Engineering) 안내
